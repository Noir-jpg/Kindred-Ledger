# Kindred Ledger

A responsive personal income and expense tracker prototype.

## Included

- Sign up/login-style entry and temporary guest mode
- Add, edit, delete, and categorize income and expenses
- Custom categories
- Live balance, monthly spending, budget, category, history, and annual chart views
- Profile and settings modals
- Light/dark appearance
- Local storage for accounts and persistent transactions; session storage for guest mode
